# OpenClaw — особистий помічник

Особистий екземпляр OpenClaw для автоматизації власних завдань Roman Tymchuk.

Доступ до сервісів Google надається власником облікового запису через Google OAuth за його згодою.

Цей сайт містить інформацію про помічника. Він не є сторінкою входу та не запитує паролі Google.
